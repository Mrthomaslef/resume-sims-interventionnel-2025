# Résumé de la SIMS interventionnelle 2025

Fiches résumés illustrées de la **4ᵉ journée « Actualités en imagerie interventionnelle » de la SIMS** (Paris, École militaire, 13 décembre 2025) : 39 fiches (une par présentation), 153 captures de diapositives.

- Ouvrir `index.html` (fonctionne hors-ligne, y compris en `file://`).
- Données : `data/fiches.json` + `data/embedded_data.js` ; images : `img/`.
- Chaîne de production (hors dépôt, sur `/Volumes/GamingSSD/sims-interventionnel-2025/`) : vidéos SIMS → transcription mlx-whisper (large-v3-turbo) → planches de vignettes → rédaction par session → `scripts/build.py` (extraction des diapos recadrées + génération des données).
